# WinSwitcher — Windows 窗口一键切换小工具

一个极小（约 14 KB）的圆形悬浮图标，贴在屏幕**最右侧垂直居中**，平时半透明、低调不抢眼。
**单击图标直接轮换到下一个窗口**——连点会按最近使用顺序依次遍历所有已打开（未最小化）的窗口，类似"按住 Alt 连续按 Tab"的效果，无需列表、无需选择。

## 功能

- 右边缘圆形小图标（⇄）：中灰蓝底色保证在深色窗口和浅色壁纸上都能看见，鼠标悬停/按下时变蓝；分层窗口真 Alpha 抗锯齿，边缘平滑
- **左键单击：轮换到下一个窗口**；所有未最小化的窗口都会参与轮换，**最小化的窗口自动跳过**，还原后自动重新加入
- **按住拖动**可把图标挪到顺手的位置
- 右键菜单（系统原生菜单）：**开机自动启动** / 退出；点击菜单外任意位置或按 Esc 即关闭
- 切换顺序遵循最近使用原则：内部维护窗口顺序，自己触发的切换不打乱次序，因此连点可遍历全部窗口；手动点击某个窗口则会把它提到最前；自动过滤工具栏小窗、UWP 挂起窗口、自身
- 图标窗口不抢焦点（`WS_EX_NOACTIVATE`），不干扰前后台判断，也不出现在 Alt+Tab 中
- **始终保持最上层**：别的置顶窗口（或全屏应用）把它盖住时，会在前台切换的瞬间立即、并每秒兜底重新声明置顶，自动浮回最上面（不抢焦点、不移动位置）
- 单实例运行

## 运行

双击 `Switcher.exe` 即可（绿色单文件，无需安装任何运行时，依赖系统自带的 .NET Framework 4.x）。

启动后屏幕**右边缘中部**会出现一个带 ⇄ 箭头的小圆点，单击即切换。

## 从源码编译

双击 `build.bat`，或在本目录执行：

```bat
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe ^
  /nologo /codepage:65001 /target:winexe /platform:anycpu ^
  /win32manifest:app.manifest /out:Switcher.exe Switcher.cs
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `Switcher.cs` | 全部源码（Win32 窗口枚举/激活 + 分层窗口自绘圆形图标） |
| `app.ico` | 多尺寸应用图标（16–256px），编译时嵌入 exe，与悬浮按钮同图案 |
| `gen-icon.ps1` | `app.ico` 的生成脚本（PowerShell + System.Drawing，无需额外工具） |
| `app.manifest` | 声明系统级 DPI 感知，高分屏不糊 |
| `build.bat` | 一键编译脚本 |
| `Switcher.exe` | 编译产物，可直接拷贝使用 |

## 备注

- 图标默认在**主显示器**右边缘，可用鼠标拖动改变位置。
- 切换逻辑：通过全局前台窗口事件维护一份最近使用窗口列表，每次点击激活列表中当前窗口的下一个，到底后回到最前循环；最小化、关闭的窗口会被自动剔除，新打开的窗口自动加入。
- 开机自启通过 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现，仅写入当前用户，取消勾选即清除。
